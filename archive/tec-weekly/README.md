# Weekly TEC register snapshots, December 2025 to November 2026

NESO publishes only the current Transmission Entry Capacity register. These 53 weekly copies (file date = the day the copy was taken, usually a Tuesday) come from a public GitHub archive, edcongreave/TEC-and-4C, which downloads the NESO file each week. The data is NESO's.

Check made 21 Nov 2026: the copy dated 2026-11-17 matches our own NESO download of the 16 November 2026 register row for row (2,188 rows, same project numbers, dates, MW, Gate, site and customer after normalising date and number formats).

Status of figures drawn from these files: Reported (third-party copy of a NESO file). A current value is Confirmed only against a register we downloaded from NESO ourselves.

Key: Project Number (Project ID switches between two ID formats in some weeks). Run: python3 -I scripts/history.py archive/tec-weekly history 2026-05-19
